## What happened

Shipped org-os v3.5.0. The release that takes org-os from "self-hosting framework"
to "real orgs can clone and operate." Five sub-plans landed:

1. **Cloning engine** — `scripts/clone-framework.mjs` is the keystone. Single
   command: identity capture → strip framework-only artifacts → render templates
   → materialize packages → npm install + validators → git init. Producing a
   passing instance in under a minute. GitHub Template wrapping in place.

2. **Package consumption** — `scripts/sync-packages.mjs` materializes vendored
   packages per `federation.yaml` toggles, pinned to `framework_version`.
   `dashboard` package promoted to framework as the first real consumer.

3. **Reliability layer** — pre-commit hook + CI workflow (`.github/workflows/
   validate.yml`) + scheduled drift workflow + `npm run selftest` aggregator.
   Federation SLA: 30 days drifted, 90 days dormant.

4. **One-pager templates** — `templates/README.framework.md`,
   `templates/README.instance.md`, `templates/GETTING-STARTED.md`, all rendered
   via a minimal Mustache-style engine. Framework README replaced;
   `GETTING-STARTED.md` is the new conversational onboarding artifact.

5. **bread-coop-os live** — bootstrapped via the engine, validators pass,
   dashboard rendering, on its own main branch with a clean bootstrap commit.
   The acceptance test passed.
