**Per-instance procedure** (see `docs/migrations/v3-to-v3-5.md` for full version):

```bash
# In instance directory:
npm run vault:snapshot -- "pre v3.5 sync"
git pull upstream main
npm run migrate -- --target v3.5    # uses new v3-to-v3-5-consolidation.mjs
npm run validate:structure
npm run validate:schemas
npm run selftest
npm run check:divergence
# Operator resolves any divergences manually
git add federation.yaml data/packages-matrix.yaml memory/migrations-*.md
git commit -m "chore: sync to org-os v3.5.0"
```

**Note on chicken-and-egg**: instances at v3.0 don't have `scripts/sync-upstream.mjs` yet (it lands WITH v3.5). The first sync is therefore manual git pull. After 3.5 lands, subsequent syncs use the new mechanism. The migration handles lineage stamp seeding.
