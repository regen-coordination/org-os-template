## Key research finding — the original approach was not viable

Multica's daemon provider registry is **hardcoded** (`defaultAgentCommandNames` + explicit `probe()` calls in `server/internal/daemon/config.go`). A custom `org-os` CLI on PATH is never auto-detected, so "org-os as an agent provider" requires forking Go. Multica's *supported* customization layer is the **Agent** (instructions markdown + skills, riding a detected runtime like `claude`), plus a **`local_directory` project resource** (`server/internal/handler/agent.go`) binding tasks to an existing directory instead of a fresh worktree.

Phase 1 was rewritten around that: an "org-os operator" **persona** rather than a CLI shim. Cheaper, no fork, and upstreams as an agent-template JSON PR instead of a Go provider PR.

## The important lesson: prefix-match deny rules are not a boundary

Review + live probing showed `permissions.deny` prefix patterns are trivially evaded:

- `git -c core.pager=cat stash list` → **ran**, despite `Bash(git stash:*)`. Any inserted global option (`-c`, `-C`, `--no-pager`, `--git-dir=`) defeats the prefix.
- `git reset -q --hard` → **ran**, despite `Bash(git reset --hard:*)`. Flag reordering defeats it.
- `git reset --ha` also destroys (git accepts unambiguous long-option abbreviations).

Fix: a `PreToolUse` hook on `Bash` that regex-matches the whole command string (deliberately not parsing shell grammar — safe-fail bias), wrapped as `node <guard> || exit 2` because Claude Code treats a non-2 non-zero exit as **non-blocking** — a crashed guard would silently reopen the boundary. Deny rules kept as defense in depth.

**Probe design matters:** only *harmless* commands prove anything. A destructive probe (`git reset --hard`) gets refused by the model on CLAUDE.md grounds without ever attempting the Bash call, so the permission layer is never exercised and you learn nothing. `git clean -n` and `git stash list` are the right probes.

## Known bypasses the guard does not catch (accepted)

Indirection through a script file; obfuscation (`$(echo git) stash`, variables); out-of-scope destructive equivalents (`git checkout -- .`, `git restore .`, `rm -rf`); non-Bash execution paths. Aimed at accidents, not a determined adversary.
