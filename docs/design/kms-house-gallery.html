org-os-kms · the knowledge system · interface

A knowledge commons, drawn like the house.

Every surface org-os-kms writes, redrawn with the DAO-OS house element set: the federation map laid out in layers, the commons as data rows, each entry as a page with a Fraunces title and a 68-character measure. Kinds are told by glyph, never by colour. Moss marks the selected path; clay marks what needs a steward: a peer that couldn’t be read, a frontier never fetched, a reference that points nowhere. The organisation, places and peers are invented placeholders.

The federation map

render map html writes one self-contained page. The layout is computed, in layers by the direction knowledge travels: what feeds the instance above it, the instance at the centre with its peers beside it, what it feeds below, and each peer-of-a-peer one hop further out from whoever reported it. This is the steward’s copy, so it carries attention; the public copy does not.

      Community seed libraries

      A seed library lends seed the way a book library lends books: borrow in spring, return saved seed in autumn. Kept by a neighbourhood, it keeps the varieties that suit the place in circulation.

      Reviewed for explanation. This entry explains the idea; it is not yet guidance for starting one. For what one group actually did, read the implementation record below.

      How it works

      Members borrow a packet, grow it out, and save seed from the strongest plants. What comes back is a little better suited to the valley than what went out. Over a few seasons the collection drifts toward what grows here.

      Known tensions

      • Returns are uneven: a dry year means fewer packets come back than went out.
      • Cross-pollinating crops need distance a small garden can’t give.
      • A library is only as good as its ledger, and ledgers are tedious.

      Territory explorer

      The territory pack’s explorer, on the same elements. Each layer is a tree (house §9.7); the selected place is moss and the places it overlaps on other layers carry an overlap mark with their share. The place opens in an inspector: field rows, what is placed here, what it overlaps, the data about it. “Who sees what” becomes the house’s View as.

      States

      The kms-specific states, each drawn with the house’s treatments. Two rules decide most of them: attention (clay) appears only on the steward’s side — the map artifact and the preview — never on public pages; and on a public page, a reference to something private and a reference to nothing look the same, because both are simply absent.
