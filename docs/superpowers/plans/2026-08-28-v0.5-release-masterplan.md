4. One versioning story: `v0.5.0` tag pushed; CHANGELOG `[0.5.0]` folded (incl. symbient, doctor); VERSIONING.md 0.x policy; MASTERPLAN.md aligned; `version:check` green.
5. Site live at `https://regen-coordination.github.io/org-os-template/` (200s on all routes, `map.json` fetch works), auto-deploy on push to main, repo homepage + README link set.
6. Branch topology after release: `main` + frozen-work archive tags only; zero worktrees; nothing unreachable (`git rev-list` proof per deletion recorded in the triage report).
7. Every plan/spec/queue entry carries its v0.5 verdict + pointer here (WS-F stamping pass — mechanical batch delegated 2026-08-28).
8. DECISIONS.md records: memo adoption + doctor amendment, deploy target, versioning story, branch-clearing policy.

Explicitly **not** in v0.5 (v0.6 floor = external pilot gate, per memo §1): module engine beyond manifest-first, admin M2/M3, cloudflare-os deploy half, dfos, rad-org-os/kms-connector/tech-tree/knowledge-commons merges, wizard non-interactive mode (B2) + BOOTSTRAP reconciliation (B1) — *except* the two cheap doc honesty fixes (M1, M3) which ship in WS-F.
