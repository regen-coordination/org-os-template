## Why this exists

`doctor sync` now works — the file-level overlay replaced the rebase and was
accepted end to end against `refi-med-os` (all nine stages, 0 blockers). Seven
instances remain unsynced, blocked **only** by the doctor's dirty-tree refusal.

That refusal was written when stage 5 was `git pull --rebase`, which rewrites
the entire working tree — so any uncommitted file anywhere was genuinely at
risk. The overlay writes a computed, narrow file list instead, so the gate is
now far too coarse. Measured across the fleet on 2026-08-29:

| Instance | Dirty | Files the overlay would actually write |
|---|---:|---:|
| bread-coop-os | 9 | **0** |
| regen-coordination-os | 24 | **0** |
| refi-bcn-os | 34 | **0** |
| refi-dao-os | 177 | **0** |
| regen-toolkit | 3,005 (2,994 generated `kb-graph/`) | **0** |
| dao-os | 7 | **1** (`scripts/update-version.mjs`, untracked) |

~3,250 uncommitted files across six instances; **one** genuine collision. Five
of the six "in scope" hits were instance-authored scripts the framework does
not have (`onboard-member.mjs`, `lib/keccak.mjs`, …) — the overlay never
touches them, because it only writes paths the framework owns and never
deletes.

## The work

### A. Make the dirty gate plan-aware (TDD)

The honest question is not *"is the tree clean?"* but *"does any uncommitted
change intersect the files this run will actually write?"* — and
`overlayPlan()` already computes that list exactly.

- In `packages/instance-doctor/src/run-sync.mjs`, the snapshot stage currently
  aborts on `foreignDirtyEntries(...)` being non-empty. Narrow it to the
  intersection of foreign dirty paths with the overlay's planned writes
  (`add` + `update`, not `unchanged`).
- Keep the abort message naming the exact colliding files and how to resolve
  them. A refusal must stay legible.
- Keep `--dry-run` fully read-only.
- Tests (root `tests/`, per the house rule): a dirty `data/members.yaml` must
  **not** block; a dirty framework-owned file the overlay would write **must**;
  an instance-authored `scripts/our-tool.mjs` the framework lacks must **not**.
- Full gate suite green before moving on.

### B. Sync the fleet, in this order

Snapshot is automatic (stage 1) — but re-verify each instance's state before
and after, and stop on the first surprise.

1. **`bread-coop-os`** — 8 blockers, 0 collisions, alpha, no git remote. Highest
   value, lowest risk. Expect the missing-remote finding to persist: that is
   correct and operator-resolved, not a sync failure.
2. **`regen-coordination-os`** — 9 blockers incl. template-leakage and the
   duplicate `initialize` key. This is the original WS-H H3 "messy real
   instance" target.
3. **`dao-os`** — first resolve its one collision: `scripts/update-version.mjs`
   is an untracked copy of a framework script. Commit it if it was deliberately
   customised, delete it if it was a stray copy — **ask the operator which**,
   then sync.
4. **`regen-toolkit`** — registered 2026-08-29, never synced. Its 2,994 dirty
   files are generated `kb-graph/` output; do not commit them, and do not treat
   them as authored work.

**Do NOT sync `refi-bcn-os` or `refi-dao-os`** without an explicit operator
green-light in that session. They are production, and `refi-dao-os` carries the
two 🔴 kms data-loss items that gate v0.6 Active-1.

## Safety (non-negotiable)

- Never `git stash`, `git clean`, or `git reset --hard` — in this repo or any
  instance. `npm run vault:snapshot -- "<reason>"` is the checkpoint.
- **Never commit or discard an operator's uncommitted work in an instance.** If
  a genuine collision appears, stop and ask.
- Stage explicit paths only, never `-A`.
- The guard reads the whole Bash command line: a heredoc body quoting a real
  destructive git command is refused. Use the Write tool for such files.
- `main` moves under you — a concurrent session has been committing all
  weekend. Re-fetch immediately before any push or tag.

## Acceptance

Gate change: full suite green, new tests pin both directions. Fleet: each
synced instance re-assesses with **fewer blockers than it started**, its
identity and root commit unchanged, a receipt written, and `last_sync_commit`
stamped. Any instance that cannot reach that state is reported honestly rather
than forced — the WS-H precedent.
